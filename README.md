# Day 1: Interactive Hello World

A modern, interactive, and responsive "Hello World" homepage built with pure HTML, CSS, and Vanilla JavaScript.

## ✨ Features

- 🌐 **Multilingual Greetings**: Click "Hello, World!" or the **Translate** button to cycle through 10 languages (English, Spanish, French, Nepali, Japanese, German, Italian, Chinese, Hindi, and Binary).
- ⌨️ **Terminal Typewriter Effect**: Rotating inspirational programming quotes and milestones.
- 🎨 **Multi-Theme Support**: Instant theme switching between **Dark Mode**, **Light Mode**, **Aurora Glow**, and **Cyberpunk**. State persists across refreshes!
- 🎊 **Confetti & Click Counter**: Click **"Say Hello Back!"** to fire confetti explosions and rack up clicks.
- 🎹 **Musical Keys / Synthesizer**: Interactive soundboard built using the Web Audio API (zero external audio files). Click the keys or press <kbd>H</kbd>, <kbd>E</kbd>, <kbd>L</kbd>, <kbd>O</kbd>, <kbd>W</kbd> on your keyboard.
- 🌌 **Constellation Background**: Ambient floating particles on HTML5 Canvas that interact with your mouse cursor.
- ✅ **Interactive Day 1 Quest**: Complete interactive tasks that celebrate with celebratory confetti upon completion.
- ⏱️ **Real-Time Clock & Session Metrics**: Live local time and session duration counter.

## 🚀 How to Run

### Option 1: Direct File
Simply double-click [`index.html`](file:///Users/binayghimire07/Documents/Day-1/index.html) to open it in your favorite browser.

### Option 2: Local HTTP Server
Run with Python:
```bash
python3 -m http.server 3000
```
Then visit: [http://localhost:3000](http://localhost:3000)

Or with Node:
```bash
npx serve .
```
